# 자배원 심사용 진단서 작성기 (ta-cetification-maker)

자동차손해배상진흥원(자배원) 및 보험사 심사를 위한 경상환자 장기치료(8주 초과) 진단서/소견서 자동 생성기입니다.

## 🚀 주요 기능

- **사고 발생일 및 8주 초과 자동 연산**:
  - 사고일 입력 시 8주 초과 시점(사고일 + 57일) 및 추가 치료 기간(2주/3주/4주) 자동 계산
  - 날짜 형식(`XXXX.XX.XX.`) 및 주간 한글 병기(`X(한글)주간`) 자동 포맷팅
- **치료 기간 연장 필요 사유 입력**:
  - 환자의 주요 잔존 증상, 이학적 검사 결과(NRS, Spurling, ROM 등) 입력 및 기본 예시 지원
- **영상검사 세부 정보 기록**:
  - 시행/미시행 선택 (시행 시 파란색, 미시행 시 빨간색 강조)
  - 시행일자, 검사 의료기관, 검사 부위(3x3 배치), 검사 종류(MRI, CT, X-Ray), 판독 소견 지원
- **실시간 결과 편집 및 복사**:
  - 생성된 진단서 결과를 텍스트 박스에서 즉시 수정 후 원클릭 복사(`진단서 복사`)
  - 진단서 하단 규정 문구 자동 삽입
  - 진단서 '용도' 항목 전용 문구 원클릭 복사(`용도 복사`)
  - 진단서 '비고' 항목 전용 문구 원클릭 복사(`비고 복사`)
- **반응형 2열 레이아웃**:
  - PC 환경: 좌측 폼 입력, 우측 스티키(Sticky) 결과값 실시간 확인
  - 모바일 환경: 최적화된 모바일 뷰 제공

## 💻 사용 기술
- HTML5, Modern Vanilla JavaScript
- Tailwind CSS (CDN)
- Pretendard Font
